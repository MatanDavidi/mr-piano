# Requirements
1. Unity Version 6000.2.8f1
2. Developer Mode on Quest 3 enabled (https://developers.meta.com/horizon/documentation/native/android/mobile-device-setup/)

# Installation
1. Clone repository: git clone https://github.com/MatanDavidi/mr-piano.git
2. Open project in Unity Version XXXX
3. Download Model files from https://polybox.ethz.ch/index.php/f/4289209958 and put them in the scene tree: path/to/sentis managers: field
4. Connect your Quest 3 USB
5. Enable USB Debugging (If not prompted, see: https://developers.meta.com/horizon/documentation/unity/unity-development-overview/)
6. Go to Project Settings -> Build Device and choose your Meta Quest
7. You can now build the app using CTRL + B
